THE MISSION

24 HOURS.
ONE ROBOT.
ZERO ROOM FOR ERROR.

Path Finder is a 24-hour hardware-based engineering challenge where participants design, assemble, wire and program an autonomous line follower robot using components provided by the organizers.

01 / HARDWARE

EMBEDDED SYSTEMS

Program Arduino Nano CH340 microcontrollers, configure pin routing, and optimize execution timing.

02 / POWER

ELECTRONICS

Wire L298N motor drivers, route 2S lithium battery power, and manage voltage regulation.

03 / CONTROL

CONTROL SYSTEMS

Implement Proportional-Integral-Derivative (PID) feedback loops to eliminate path oscillation.

04 / FABRICATION

HARDWARE ASSEMBLY

Mount motors, solder pin headers, attach castor wheels, and optimize chassis weight balance.

05 / FIRMWARE

ROBOT PROGRAMMING

Write C code to sample 5-channel IR reflection thresholds and translate error signals into PWM motor speeds.

06 / STRATEGY

TEAMWORK

Collaborate within 4-member squad roles under high-stakes 24-hour sprint conditions.

07 / LOGIC

PROBLEM-SOLVING

Debug real-time sensor reflections, surface reflectivity changes, and dynamic track turns.

ROUND 01 — QUIZ ROUND

Understanding Concepts

A technical assessment covering embedded systems, electronics, sensors and actuators, control systems, programming concepts, and line follower robot fundamentals.

02 CALIBRATE

ROUND 02 — HARDWARE SETUP

Build • Wire • Program • Calibrate

Teams must assemble the robot, complete the electrical connections, solder the required components and program the Arduino Nano. After completing the hardware setup, teams will receive a basic line follower track for PID tuning and robot calibration.

03 LOCK ON

Track • Precision • Speed

Teams compete on the final race track using the robots developed during the hackathon. THE FINAL RACE TRACK WILL BE REVEALED ONLY AT THE BEGINNING OF ROUND 3. Teams must build adaptable PID algorithms capable of handling unannounced turns, curves and intersections.
